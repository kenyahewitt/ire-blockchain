Become a validator

You need uire in a local key for self-delegation and fees (minimum-gas-prices is 0.001uire). There is no public faucet. The create-validator transaction will fail until an existing holder sends uire to your address. After the node is synced:

The create-validator transaction will fail until this account has a balance. Ask an existing token holder to send uire to the address from ired keys show myvalidator -a --home "$HOME/.ire". Do not treat the current local operator as a mainnet set; there is still one validator.
