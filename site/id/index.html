Profile

Your IRE id

Every ire1 can publish a profile: name plus X, Telegram, Discord, or a site. It is an on-chain memo (ire-id), same 256-character limit as other inscriptions. Share the address so people can receive or send. This page never holds a key.

Socials are public

Whatever you inscribe is on every node. Do not put emails, phones, or seed phrases in the memo.

Receive and send

Receive link opens Wallet with your address filled. Send still signs locally. Points for using the chain: Points.

Latest memo wins

A new op:set from the same ire1 replaces the profile the indexer shows. Nothing is deleted from history.
