How to read this

Each cube is a transaction. Color is by kind, not by fee. Inscription ids are {txhash}i{index} — lowercase hex, the letter i, then the message index. Click a cube or a block for the hash and, when present, the memo payload. Send and inscribe from Use.

This page never asks for a key and never broadcasts. The public seed is P2P only: 63c21a2befb884a958cdc88a1c78788eae42bf5b@91.99.1.9:26656.
